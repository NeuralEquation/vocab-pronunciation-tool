# 教材インポート形式

推奨形式は **JSON配列**。1語につき1オブジェクトにまとめます。サンプルは [vocabulary-import.json](../examples/vocabulary-import.json)。このサンプルの発音表記は形式説明用です。

| 項目 | 内容 |
| --- | --- |
| `word` | 見出し語・動詞の原形。必須 |
| `meaning` | 日本語の意味。必須。複数の意味は `／` 区切り。従来の `meaningsJa` 配列も使用可 |
| `partsOfSpeech` | 品詞の配列。`["noun", "verb"]` のように複数指定可 |
| `pronunciations` | 品詞ごとの米国英語IPA。各項目に `partOfSpeech` と `ipa` を記載 |
| `verbForms` | 動詞の活用形。`past`、`pastParticiple`、`presentParticiple`、`thirdPersonSingular`。各値は文字列の配列 |
| `examples` / `phrases` | 従来どおり、`en` と `ja` を持つ項目の配列 |

`partsOfSpeech` の代表値は `noun`（名詞）、`verb`（動詞）、`adjective`（形容詞）、`adverb`（副詞）。代名詞、前置詞、接続詞、冠詞、助動詞、自動詞、他動詞などにも対応します。従来の `partOfSpeech: "verb"` や `"v."` も取り込み時に受け付けます。

品詞・発音・活用形は任意です。教材にない情報を推測で埋める必要はありません。従来のJSON・JSON Lines・6列TSVも引き続き使えます。追加情報を登録する場合はJSONを使ってください。

動詞の活用欄は、動詞の品詞がある語だけに表示します。品詞不明の語には活用欄を出しません。以前の形式で活用形だけ登録した語は、データを失わないよう動詞として扱います。旧データの品詞は画面から編集できます。新規インポートで名詞だけを指定しながら活用形を付けるなど、矛盾するデータは登録前にエラーにします。

## 品詞別の発音

Merriam-Webster APIは単語単位で検索し、各辞書項目の `fl`（品詞）と `hwi.prs`（発音・音声）を返します。リクエストに品詞を追加して読み方を変える方式ではありません。

アプリは選択した品詞に一致する公式音声を選びます。複数の品詞を持つ語は「読み上げる品詞」で切り替えられ、選択を保存します。初期選択は教材で指定した最初の品詞です。教材の品詞・IPAは辞書キャッシュと別に保持するため、辞書の再取得やキャッシュ削除で消えません。

`pronunciations` には、APIや辞書で確認した `audioId` も任意で付けられます。音声IDを単語から推測して作ってはいけません。音声IDがない場合は、APIで取得した同じ品詞の公式音声を使います。該当音声がなければ未取得として扱い、別品詞の音声には置き換えません。

**IPAは表示用の発音情報であり、ブラウザの端末TTSに発音を指示する命令ではありません。** 品詞を明示した語や複数品詞の読み分けでは、公式音声が利用できなければ曖昧なTTSに自動切り替えしません。熟語全文・活用形などの通常の端末TTSには、このような読み分け保証はありません。

品詞・発音・選択はバックアップにも含まれます。GAS同期を使う場合は、更新した共有プロトコル・Storageを含むGAS側の再配置も必要です。旧GAS側には新項目を送信できません。
